# 2. Leseverstehen (Reading)

## Format (typical)
1. **Zuordnung** — match people/ads/situations  
2. **Richtig / Falsch** — true/false about a text  
3. **Multiple Choice** — choose a/b/c  

## Strategy
1. Read **questions first** → underline keywords  
2. Scan text for **synonyms** (not the same words!)  
3. Don’t panic if you don’t know every word  
4. Watch traps: *sofort* vs *letzter Ausweg*, *nur* vs *auch*

## Synonym training (examples from your course)

# 3. Sprachbausteine (Language building blocks)

## What it is
A letter/email with gaps. Choose the correct word (grammar + vocab).

## What they love to test (from YOUR grammar)

| Topic | Examples |
| :--- | :--- |
| Connectors | weil, obwohl, trotzdem, deshalb, denn, deswegen, wegen |
| Relative pronouns | der/die/das/den/dem/denen |
| Konjunktiv II | wäre, hätte, würde, könnte, müsste |
| Passiv | wird gemacht / muss gemacht **werden** |
| Infinitiv mit zu | versuchen zu … / es ist wichtig zu … |
| um/statt/ohne … zu | um zu arbeiten, statt zu lernen, ohne zu frühstücken |
| Zweiteilige Konjunktionen | nicht nur…sondern auch / zwar…aber / entweder…oder |
| Genitiv | wegen des Wetters, des Mannes |
| Adjective endings | ein neues Auto / das neue Auto |
| Prepositions / pronouns | bei Ihnen, mir/dir, für mich |

## Mini checklist before you choose an answer
1. Case? (Nom/Akk/Dat/Gen)  
2. Connector type? (verb to end or position 2?)  
3. Same subject → *um/statt/ohne … zu*?  
4. Modal → usually **no** *zu*?

# 4. Hörverstehen (Listening) — your weak point → priority

## Format (typical)
- Short dialogues / announcements  
- Longer conversation / interview  
- Tasks: Richtig/Falsch, multiple choice, matching  

## Strategy
1. **Read questions BEFORE audio**  
2. Listen for names, times, places, reasons (*weil/wegen*), decisions (*entweder…oder*)  
3. First listening = global idea; second = details  
4. Accept that you won’t catch every word

# 5. Schreiben (Writing)

## Typical tasks
1. **E-Mail / Brief** (formal or informal) — request, complaint, invitation, apology, neighbour, job  
2. **Forum / Meinung** — give opinion on a statement (~80 words)

## Must-have structure

### Formal email
```
Sehr geehrte/r …,
[Grund] …
[Details / Bitte] …
[Dank / Hoffnung]
Mit freundlichen Grüßen
Name
```

### Forum opinion
```
Hallo …,
Ich denke, dass …
Zwar …, aber … / Einerseits …, andererseits …
Wenn ich du wäre, würde ich …
Ich stimme … (nicht) zu, weil …
Viele Grüße
```

## Phrases that win points
- Vielen Dank im Voraus.  
- Könnten Sie bitte …?  
- Ich freue mich auf Ihre Antwort.  
- Meiner Meinung nach …  
- Es ist wichtig, … zu …  
- Wegen + Genitiv / weil + clause  

## Topics you’ve practised
- Paket beim Nachbarn  
- Mehrsprachigkeit (Sandra forum)  
- Bewerbungsschreiben  
- Gesundheit / Schlaf tipps  
- Traumjob / Leben in Deutschland  

**Rule:** Cover **all bullet points** in the task. Clear structure > fancy vocabulary.

# 7. Grammar master list (B1.1 → exam)

### Connectors
| Word | Verb position | Meaning |
| :--- | :--- | :--- |
| weil / obwohl / dass / wenn / als | end | because / although / that / when(if) / when(past once) |
| deshalb / trotzdem / deswegen | position 2 | therefore / nevertheless |
| denn | main-clause order | because |
| wegen | + Genitiv | because of |

### als vs wenn
- **als** = one time / period in the **past**  
- **wenn** = present/future OR repeated past  

### Relativsätze
der/die/das · den · dem · denen · die (Pl.)

### Konjunktiv II
wäre, hätte, würde, könnte, müsste, sollte  
*Wenn ich du wäre, würde ich …*

### Passiv
wird + Partizip II  
Modal: muss/sollte + Partizip II + **werden**

### Infinitiv mit zu
versuchen/Lust haben/Zeit haben/es ist wichtig + **zu**  
Separable: ein**zu**kaufen  

### Final / alternative / without
um … zu · statt … zu · ohne … zu  
(same subject)

### damit
different subject possible: *damit du verstehst*

### Zweiteilige Konjunktionen (L7)
nicht nur …, sondern auch …  
zwar …, aber …  
entweder … oder …

### TeKaMoLo
Temporal → Kausal → Modal → Lokal  
*Ich fahre morgen wegen des Regens mit dem Bus zur Arbeit.*

### Adjective endings (3 situations)
nach der/die/das · nach ein/mein · ohne Artikel  

### brauchen vs müssen
brauchen (+ nicht/nur) + **zu**  
müssen + Infinitiv (no zu)
