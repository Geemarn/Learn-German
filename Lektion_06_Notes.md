# Lektion 6 — Dienstleistungen (Teil 1)

**Theme:** Services (Dienstleistungen), good employees, purpose clauses  
**Grammar:** Finalsatz — **um … zu** vs **damit**  
**Communication:** Opinions about a good employee  
**Also:** Hörverstehen (first listening text from L6)

---

## 1. What is a Dienstleistung?

**Dienstleistung** = service  
Something someone does for another person, usually for money (not a physical product).

### Wortbildung
**Dienst** + **Leistung** = Dienstleistung

| Part | Meaning | Examples |
| :--- | :--- | :--- |
| **der Dienst** | service / duty / work for someone | Militär**dienst**, Kunden**dienst**, Not**dienst** |
| **die Leistung** | performance / achievement / service provided | eine gute **Leistung**, sportliche **Leistung**, **Leistungen** einer Firma |

### Example sentences
- Der **Kundendienst** hilft mir bei Problemen mit meinem Handy. *(Customer service helps me with phone problems.)*  
- Am Wochenende gibt es einen **Notdienst** bei der Apotheke. *(At the weekend there is an emergency pharmacy service.)*  
- Die Firma bietet viele **Dienstleistungen** an. *(The company offers many services.)*  
- Das war eine sehr gute **Leistung**! *(That was a very good performance / achievement.)*

### Typical Dienstleistungen (examples)
| German | English |
| :--- | :--- |
| die Reinigung | cleaning service |
| die Reparatur | repair |
| der Kundendienst | customer service |
| der Lieferservice | delivery service |
| die Beratung | advice / consulting |
| der Friseur / die Friseurin | hairdresser |
| die Bank / Versicherung | bank / insurance |

## 2. Grammar — Finalsatz (purpose / goal)

**Question word:** **Wozu?** = What for? / To what end?

### A) um … zu + Infinitiv
Use when **the same subject** does both actions.

**Formula:**  
Hauptsatz, **um** … **zu** + Infinitiv

| German | English |
| :--- | :--- |
| Ich lerne Deutsch, **um** in Deutschland **zu arbeiten**. | I learn German in order to work in Germany. |
| Ich spare Geld, **um** ein Auto **zu kaufen**. | I save money in order to buy a car. |
| Ich gehe früh schlafen, **um** morgen fit **zu sein**. | I go to bed early in order to be fit tomorrow. |
| Ich benutze ein Wörterbuch, **um** neue Wörter **zu lernen**. | I use a dictionary in order to learn new words. |

**Separable verbs:** *zu* in the middle  
- Ich stehe früh auf, **um** pünktlich **anzukommen**.  
- Er ruft an, **um** einen Termin **zu vereinbaren**.

### B) damit + Nebensatz
Use when subjects are **different**, or when you prefer a full clause.

**Formula:**  
Hauptsatz, **damit** + Subject + … + Verb (at the end)

| German | English |
| :--- | :--- |
| Ich erkläre das langsam, **damit du** mich **verstehst**. | I explain it slowly so that you understand me. |
| Die Firma bietet einen Kundendienst an, **damit die Kunden** zufrieden **sind**. | The company offers customer service so that customers are satisfied. |
| Ich lerne Deutsch, **damit meine Kinder** auch Deutsch **sprechen**. | I learn German so that my children also speak German. |

### um … zu vs damit

| | **um … zu** | **damit** |
| :--- | :--- | :--- |
| Same subject? | **Yes** (usually) | Often **different** subjects |
| Form | um + (object) + zu + Infinitiv | damit + full clause |
| Example | Ich lerne, **um** zu arbeiten. | Ich lerne, **damit mein Chef** zufrieden ist. |

**Same subject — both possible:**
- Ich spare Geld, **um** ein Auto **zu kaufen**.  
- Ich spare Geld, **damit ich** ein Auto **kaufen kann**.

## 3. Ein guter Mitarbeiter — Adjektive

| Adjektiv | Meaning | Example sentence |
| :--- | :--- | :--- |
| **freundlich** | friendly | Ein guter Mitarbeiter ist immer **freundlich**. |
| **pünktlich** | punctual | Es ist wichtig, **pünktlich** zu sein. |
| **ehrlich** | honest | Man sollte **ehrlich** zu den Kunden sein. |
| **hilfsbereit** | helpful | Sie ist sehr **hilfsbereit**. |
| **flexibel** | flexible | Im Kundendienst muss man **flexibel** sein. |
| **zuverlässig** | reliable | Ein **zuverlässiger** Mitarbeiter kommt jeden Tag. |
| **kommunikativ** | communicative | Für Beratung sollte man **kommunikativ** sein. |
| **teamfähig** | good at teamwork | Ich finde **Teamfähigkeit** sehr wichtig. |
| **kreativ** | creative | **Kreative** Mitarbeiter finden neue Ideen. |
| **motiviert** | motivated | Man muss **motiviert** sein, um gut zu arbeiten. |

### Redemittel (opinion phrases)
| Phrase | English |
| :--- | :--- |
| Ich denke, dass … | I think that … |
| Ich glaube, dass … | I believe that … |
| Ich finde …, weil … | I find … because … |
| Es ist wichtig, … zu … | It is important to … |
| Man muss … | One must … |
| Man sollte … | One should … |

### Model answers: Was macht einen guten Mitarbeiter aus?
- Ich denke, dass ein guter Mitarbeiter **zuverlässig** und **pünktlich** sein sollte.  
- Ich finde **Hilfsbereitschaft** wichtig, **weil** man im Team arbeitet.  
- Es ist wichtig, **freundlich zu sein**, **um** die Kunden zufrieden **zu machen**.  
- Man muss **flexibel** sein, **damit** die Firma gut funktionieren kann.  
- Ich glaube, dass man **motiviert** sein sollte, **um** eine gute **Leistung** **zu bringen**.

**After listening, ask yourself:**
1. Which **Dienstleistung** is the text about?  
2. What problem does the person have?

## 5. Exercises

### A. Wortbildung — what do these mean?
1. Kundendienst = ________  
2. Notdienst = ________  
3. Militärdienst = ________  
4. eine gute Leistung = ________

### B. um … zu or damit?
5. Ich lerne Deutsch, ______ in Deutschland zu arbeiten.  
6. Ich spreche langsam, ______ du mich verstehst.  
7. Er spart Geld, ______ ein Auto zu kaufen.  
8. Die Firma schult die Mitarbeiter, ______ sie freundlicher sind.  
9. Ich stehe früh auf, ______ pünktlich zu sein.

### C. Write with um … zu
10. I go to the bank in order to open an account.  
11. She calls customer service in order to get help.  
12. We learn vocabulary in order to speak better.

### D. Opinion — complete
13. Ich denke, dass ein guter Mitarbeiter ________ sein sollte.  
14. Es ist wichtig, ________ zu ________.  
15. Man sollte ________, damit die Kunden ________.

<details>
<summary>Answers</summary>

**A**  
1 customer service · 2 emergency service · 3 military service · 4 a good performance/achievement  

**B**  
5 um · 6 damit · 7 um · 8 damit · 9 um  

**C**  
10 Ich gehe zur Bank, **um** ein Konto **zu eröffnen**.  
11 Sie ruft den Kundendienst an, **um** Hilfe **zu bekommen**.  
12 Wir lernen Wortschatz, **um** besser **zu sprechen**.  

**D** (examples)  
13 zuverlässig / pünktlich / freundlich  
14 Es ist wichtig, **freundlich zu sein**.  
15 Man sollte **helfen**, damit die Kunden **zufrieden sind**.

## 6. Mini speaking / writing task (telc useful)

**Thema:** Was macht einen guten Mitarbeiter aus?

Write 6–8 sentences. Use at least:
- 2 adjectives from the list  
- 1× *Ich denke/finde, dass …*  
- 1× *Es ist wichtig, … zu …*  
- 1× *um … zu* or *damit*

**Model paragraph**
Ich denke, dass ein guter Mitarbeiter **zuverlässig** und **freundlich** sein sollte. Es ist wichtig, **pünktlich zu sein**. Man muss **teamfähig** sein, **um** gut mit Kollegen **zu arbeiten**. Außerdem sollte man **hilfsbereit** sein, **damit** die Kunden zufrieden **sind**. Ich finde **Motivation** auch wichtig, **weil** man dann eine bessere **Leistung** bringt.
