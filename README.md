## Core grammar checklist

- **Connectors:** weil · obwohl · trotzdem · deshalb · denn · wegen (+ Genitiv)
- **als vs wenn:** *als* = single past event · *wenn* = present/future or repeated past
- **Relativsätze:** der / die / das / den / dem / denen
- **Konjunktiv II:** wäre · hätte · würde · könnte · müsste · sollte
- **Passiv:** *wird* + Partizip II · with modal: *muss … gemacht **werden***
- **Infinitiv mit zu:** versuchen / Lust haben / es ist wichtig … *zu* + Infinitiv
- **Purpose & alternatives:** um … zu · damit · statt … zu · ohne … zu
- **Zweiteilige Konjunktionen:** nicht nur … sondern auch · zwar … aber · entweder … oder
- **Proportion:** je … desto / umso
- **Word order:** TeKaMoLo (Temporal → Kausal → Modal → Lokal)
- **Adjective endings:** after der-words · after ein-words · without article

## How to use this repository

1. Read the **Lektion notes** for the chapter you are studying.
2. Do the exercises at the end of each file, then check the answer key.
3. Practise reading with `Leseverstehen_L2_L3_L4.md`.
4. Take the mock exam in `telc_B1_Probepruefung_L1-L4.md` under time pressure.
5. Review weak areas using the dedicated grammar guides.

### Listening practice (the hardest skill)

Use the three-step method for any audio:

1. Listen once without any text — catch the general idea.
2. Listen again **while reading the transcript** — connect sound to spelling.
3. Listen a third time without the text.

Recommended resources: Easy German, Deutsche Welle (*Langsam gesprochene Nachrichten*, *Nicos Weg B1*), and the Schritte audio with the transcripts at the back of the book.
