---

## 1. Review — statt … zu / ohne … zu (Lektion 6)

Same subject in both actions. Infinitive with **zu** at the end.

| Structure | Meaning | Example |
| :--- | :--- | :--- |
| **statt … zu** | instead of | Er sieht fern, **statt** für die Prüfung **zu lernen**. |
| **ohne … zu** | without | Sie geht aus dem Haus, **ohne zu frühstücken**. |

### Separable verbs
mitnehmen → **mitzunehmen**  
- Er geht aus dem Haus, **ohne** seinen Regenschirm **mitzunehmen**.  
  *(He leaves the house without taking his umbrella with him.)*

aufräumen → **aufzuräumen**  
- Sie geht schlafen, **statt** die Küche **aufzuräumen**.  
anrufen → **anzurufen**  
- Er schreibt eine Nachricht, **statt** die Nachbarn **anzurufen**.

### Quick practice
1. Ich bleibe zu Hause, ______ ins Kino zu gehen. → **statt**  
2. Er spricht mit den Nachbarn, ______ zu schimpfen. → **ohne** / or **statt** depending on meaning  
3. Wir ziehen um, ohne die Freunde ______ (informieren). → **zu informieren**

## 3. Grammar — Zweiteilige Konjunktionen (central for L7)

### A) nicht nur …, sondern auch …
= **not only … but also …**

- Die Wohnung ist **nicht nur** groß, **sondern auch** sehr hell.  
  *(The apartment is not only big, but also very bright.)*  
- Mein Nachbar ist **nicht nur** freundlich, **sondern auch** hilfsbereit.  
- Ich lerne **nicht nur** Grammatik, **sondern auch** Wortschatz.

**Word order tip:** After *sondern auch*, the sentence continues normally (often same structure as before).

---

### B) zwar …, aber …
= **admittedly / it is true that … but …**

- Die Wohnung ist **zwar** teuer, **aber** sehr schön.  
  *(The apartment is expensive, but very nice.)*  
- Die Nachbarn sind **zwar** nett, **aber** abends oft laut.  
- Ich habe **zwar** wenig Platz, **aber** die Lage ist perfekt.

**Comma** before *aber*.

---

### C) entweder … oder …
= **either … or …**

- Wir können **entweder** mit den Nachbarn sprechen **oder** einen Brief schreiben.  
  *(We can either talk to the neighbours or write a letter.)*  
- Ihr bleibt **entweder** hier **oder** ihr zieht um.  
- Ich miete **entweder** eine kleine Wohnung in der Stadt **oder** ein Zimmer außerhalb.

---

### Side-by-side

| Structure | Use when… | Example |
| :--- | :--- | :--- |
| **nicht nur …, sondern auch …** | add a second positive/extra point | nicht nur ruhig, sondern auch zentral |
| **zwar …, aber …** | concession + contrast | zwar teuer, aber schön |
| **entweder … oder …** | choose between two options | entweder sprechen oder schreiben |

## 4. Speaking — B1 opinion toolkit (Wiederholung)

Use these to give opinions, reasons, and connected arguments:

| German | English |
| :--- | :--- |
| Ich denke, dass … | I think that … |
| Ich glaube, dass … | I believe that … |
| Meiner Meinung nach … | In my opinion … |
| …, weil … | because … |
| obwohl … | although … |
| trotzdem … | nevertheless … |
| einerseits …, andererseits … | on the one hand … on the other … |
| zwar …, aber … | it is true that … but … |
| nicht nur …, sondern auch … | not only … but also … |
| entweder … oder … | either … or … |
| Es ist wichtig, … zu … | It is important to … |
| um … zu … | in order to … |
| ohne … zu … | without … |
| statt … zu … | instead of … |

### Model: Nachbar-Konflikt (Sprechen Teil)
**Meiner Meinung nach** sollte man zuerst ruhig sprechen.  
Die Nachbarn sind **zwar** laut, **aber** vielleicht wissen sie das nicht.  
**Einerseits** brauche ich Ruhe, **andererseits** möchte ich keinen Streit.  
Wir können **entweder** mit ihnen sprechen **oder** einen freundlichen Brief schreiben.  
Es ist wichtig, höflich **zu bleiben**, **statt** sofort zu schimpfen.  
Ich denke, dass man das Problem lösen kann, **ohne** gleich auszuziehen.

2. Same subject needed for *ohne … zu*? → **Yes**  
3. *mitnehmen* with zu → **mitzunehmen**
