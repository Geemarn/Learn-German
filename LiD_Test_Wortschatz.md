# Leben in Deutschland (LiD) / Einbürgerungstest — Kompletter Wortschatz

Alle wichtigen Wörter aus dem offiziellen Fragenkatalog, nach Themen sortiert, mit englischer Bedeutung und Erklärung.

## 0. Der Test — Format

| | |
| :--- | :--- |
| **Fragen** | 33 Multiple-Choice-Fragen (4 Antworten, **eine** ist richtig) |
| **Davon** | 30 allgemeine Fragen + **3 Fragen zu deinem Bundesland** |
| **Fragenkatalog** | 300 allgemeine + 10 pro Bundesland = **310 Fragen, alle öffentlich** |
| **Zeit** | 60 Minuten |
| **Gebühr** | 25 € |
| **Bestanden** | **15** richtige = Orientierungskurs bestanden · **17** richtige = gültig für die **Einbürgerung** |
| **Wiederholung** | Beliebig oft möglich, keine Minuspunkte für falsche Antworten |
| **Themen** | Leben in der Demokratie · Geschichte und Verantwortung · Mensch und Gesellschaft |

> **Wichtig:** Ziele auf **mindestens 17**, nicht 15. Nur mit 17 richtigen Antworten kannst du den Test später für den deutschen Pass benutzen.
>
> **Bester Lernweg:** Alle 310 Fragen sind veröffentlicht. Übe sie im kostenlosen [BAMF Online-Testcenter](https://oet.bamf.de/ords/oetut/f?p=514:1:::::) — die Fragen im Test sind **wörtlich dieselben**.

## 1. Prüfungssprache — die Wörter in den Fragen selbst

Diese Wörter kommen in den Fragestellungen vor. Wenn du sie nicht verstehst, verlierst du Punkte, obwohl du die Antwort weißt.

| Wort | Englisch | Beispiel aus dem Test |
| :--- | :--- | :--- |
| **Was bedeutet …?** | What does … mean? | *Was bedeutet „Rechtsstaat"?* |
| **Wer …?** | Who …? | *Wer wählt den Bundeskanzler?* |
| **Wie viele …?** | How many …? | *Wie viele Bundesländer hat Deutschland?* |
| **Wozu dient …?** | What is … for? | *Wozu dient die Gewaltenteilung?* |
| **Welche Aussage ist richtig?** | Which statement is correct? | — |
| **Was gehört **nicht** zu …?** | What does **not** belong to …? | Achtung: **nicht** = negative Frage! |
| **Was ist **kein** …?** | What is **not** a …? | *Was ist kein Grundrecht?* |
| **darf** | is allowed to | *Wer darf wählen?* |
| **muss** | must, has to | *Was muss man tun …?* |
| **gilt** (gelten) | applies, is valid | *Das Gesetz gilt für alle.* |
| **gehören zu** | to belong to | *Zu den Grundrechten gehören …* |
| **treffen zu** (zutreffen) | to be true, to apply | *Welche Antwort trifft zu?* |
| **die Aussage, -n** | statement | — |
| **die Ausnahme, -n** | exception | — |
| **das Recht, -e** | right / law | — |
| **die Pflicht, -en** | duty, obligation | — |
| **erlaubt / verboten** | allowed / forbidden | — |
| **zuständig sein für** | to be responsible for | *Wer ist dafür zuständig?* |

> ⚠️ **Die häufigste Falle:** Fragen mit **„nicht"** oder **„kein"**. Lies jede Frage zweimal und unterstreiche diese Wörter.

| **4** | **10 Berlin-Fragen** auswendig + jeden Tag ein kompletter Mustertest (33 Fragen) |

**Strategie im Test:**
1. Lies jede Frage zweimal — achte auf **„nicht"** und **„kein"**.
2. Streiche zuerst die offensichtlich falschen Antworten.
3. **Beantworte jede Frage** — es gibt keine Minuspunkte. Nie leer lassen!
4. Bei Unsicherheit: Die Antwort, die zu **Demokratie, Freiheit und Gleichberechtigung** passt, ist fast immer richtig.
