# B1 Schreiben: Paket annehmen (Asking a neighbor to accept a package)

## 1. Your Original Text
Sehr geehrte Herrn Vogel,

Morgen kommt ein Paket für Mich aber ich bin nicht zu Hause. können Sie mir bitte das Paket annehmen?.
Wann holen mich das Paket ab?

Mit freundlichen grussen
Adegoke

---

## 2. Corrected Text (Direct Corrections)
**Sehr geehrter Herr** Vogel,

**m**orgen kommt ein Paket für **mich,** aber ich bin nicht zu Hause. **K**önnen Sie **bitte** das Paket **für mich** annehmen?
Wann **kann ich** das Paket **abholen**?

Mit freundlichen **Grüßen**
Adegoke

---

## 3. Optimized B1-Level Text (Recommended for the Exam)
*(Note: For a neighbor, "Lieber Herr Vogel" or "Guten Tag Herr Vogel" is usually better than "Sehr geehrter", which is for official business, but both are acceptable if you use "Sie").*

**Lieber Herr Vogel,**

**morgen kommt ein Paket für mich, aber ich bin leider nicht zu Hause. Könnten Sie das Paket bitte für mich annehmen?**
**Sagen Sie mir bitte kurz Bescheid, wann ich es bei Ihnen abholen kann.**

**Vielen Dank im Voraus für Ihre Hilfe!**

**Viele Grüße**
**Adegoke**

---

## 4. Explanation of Mistakes
1. **Sehr geehrte Herrn Vogel** -> **Sehr geehrter Herr Vogel**: "Herr" is masculine, so the adjective needs the "-er" ending in the nominative case. "Herrn" is only used in the Accusative or Dative case (e.g., *Ich gebe Herrn Vogel das Paket*).
2. **für Mich** -> **für mich**: Pronouns like *mich* are always lowercase (unless at the start of a sentence).
3. **[...], aber** -> Always put a comma before *aber*.
4. **können Sie mir...** -> **Können Sie bitte... / Könnten Sie bitte...**: After a period, start with a capital letter. Also, using *Könnten* (Konjunktiv II) makes it sound much more polite, which gets you extra points in B1!
5. **mir ... annehmen** -> **für mich ... annehmen**: You accept a package "for" someone (*für mich*), not "to" someone. 
6. **Wann holen mich das Paket ab?** -> **Wann kann ich das Paket abholen?**: Your sentence translated to "When are catching me the package up?". You need the modal verb *kann* (can) + *ich* (I) + *abholen* (pick up) at the end.
7. **Mit freundlichen grussen** -> **Mit freundlichen Grüßen**: Nouns are capitalized, and *Grüßen* takes the "ß".

## 5. Vocabulary & Translations (Wortschatz & Übersetzungen)

### Nouns (Nomen)
*   **das Paket (die Pakete)** - package / parcel
*   **der Nachbar (die Nachbarn)** - neighbor (male)
*   **die Nachbarin (die Nachbarinnen)** - neighbor (female)
*   **die Hilfe** - help
*   **der Voraus** - advance (*im Voraus* = in advance)
*   **der Gruß (die Grüße)** - greeting

### Verbs (Verben)
*   **annehmen (nimmt an, nahm an, hat angenommen)** - to accept / to take (a package)
*   **abholen (holt ab, holte ab, hat abgeholt)** - to pick up / to collect
*   **Bescheid sagen (sagt Bescheid, sagte Bescheid, hat Bescheid gesagt)** - to let someone know / to inform
*   **könnten** - could (polite form of *können*, very useful for requests)

### Useful Phrases (Nützliche Ausdrücke)
*   **Sehr geehrter Herr [Name],** - Dear Mr. [Name], (very formal)
*   **Lieber Herr [Name],** - Dear Mr. [Name], (formal but slightly more friendly, great for neighbors you call "Sie")
*   **... aber ich bin leider nicht zu Hause.** - ... but unfortunately I am not at home.
*   **Vielen Dank im Voraus für Ihre Hilfe!** - Thank you in advance for your help! (Standard B1 closing for a request)
*   **Mit freundlichen Grüßen** - Yours sincerely (Very formal closing)
*   **Viele Grüße** - Best regards (Friendly formal closing)
