# telc B1 Lesen — how to take the 75 points

**Exam: next month.** Lesen is 75 of the 225 written points. It shares **90 minutes** with Sprachbausteine (20 + 20 items, no break).

| Part | What you do | Items | Points | Aim for |
| :--- | :--- | :--- | :--- | :--- |
| **1** | Five short texts → one headline each | 5 | 25 | 12 min |
| **2** | One longer text → a / b / c | 5 | 25 | 20 min |
| **3** | Ten situations → one ad each, or **x** | 10 | 25 | 18 min |

Leave about **40 minutes** for Sprachbausteine. A wrong answer costs that item only. Fill every box. On Teil 3, **x** is a real answer.

Your shorter practice file `telc_B1_Probepruefung_L1-L4.md` mixes the same skills (match, true/false, a/b/c). The method below is the one for the real exam.

---

# 1. The shape (say this for every item)

1. What is the **main idea**, in one short sentence?
2. Which **two facts** must both be true?
3. Is the text saying the **same thing in different words**?

Same word in the text and in the option is often the **wrong** option. The right option uses a synonym.

---

# 2. Teil 1 — headlines

Five texts, about ten headlines. Five headlines are extra. Each headline once.

1. Read **one text**.
2. Cover the headlines. Say what the **whole** text is about.
3. Then pick the headline that matches that sentence.
4. Cross the headline out.

A wrong headline often copies one word from the text (Bus, Kurs, Waschmaschine) and talks about a **detail** or the **opposite**.

| Text is really about | Reject the headline that says |
| :--- | :--- |
| He arrived late because the bus did not come | The course was cancelled |
| The repair comes next week | The machine will be repaired today |
| She likes the job but the hours are long | She wants to leave the job |

---

# 3. Teil 2 — a / b / c

The five questions follow the text from top to bottom. Find the sentence, then check the option against **that sentence**, not against what you already know about the topic.

## Twenty phrases that flip the answer

Hunt these words. They decide richtig or falsch.

| If the text says | The answer is |
| :--- | :--- |
| **nur** | not “always” and not “also” |
| **nicht mehr** | it stopped; “still” is wrong |
| **früher … heute nicht** | once yes, now no |
| **erst** | later than people expect, not “already” |
| **schon** | it has happened; “not yet” is wrong |
| **fast alle** | not “all” |
| **selten** | not “oft” |
| **kann** | possible, not “muss” |
| **sollte** | advice, not “must” |
| **gratis / kostenlos** | price is zero, not “cheap” |
| **der letzte Ausweg** | only if nothing else works, not “sofort” |
| **zwar …, aber …** | both sides; “only good” and “only bad” are wrong |
| **sowohl … als auch …** | **both** |
| **weder … noch …** | **neither** |
| **seit + present** | it started in the past and is **still true** |
| **ab 18 Uhr** | not before 18:00 |
| **ohne Anmeldung** | no need to register |
| **höchstens** | not more than that number |
| **mindestens** | not less than that number |
| **statt … zu** | they do the other thing, not the first thing |

---

# 4. Teil 3 — situations and ads

Each situation has **two** wishes. The ad must satisfy **both**. One wish is not enough.

1. Underline the two wishes (time, price, place, who it is for).
2. Kill every ad that fails one wish.
3. If none survive, mark **x**.
4. Cross out the ad you used. Each ad once.

| Situation says | Ad must also say | Still wrong if |
| :--- | :--- | :--- |
| abends, nicht am Wochenende | a weekday evening | only Saturday |
| nicht über 200 Euro | a price of 200 or less | 250 Euro |
| jemand **im Haus** nimmt das Paket an | a neighbour | a shop where **you** must go |
| reparieren **statt** wegwerfen, kostenlos | repair and free | a shop that sells a new one |
| Fitnessstudio **mit Schwimmbad** | a pool | yoga only |

---

# 5. Synonyms from your chapters

The question will not copy the text. Learn the pair.

| The text may say | The question may say |
| :--- | :--- |
| hoher Druck | Stress |
| den Bus verpassen | zu spät kommen |
| die Muttersprache | die erste Sprache |
| sich beschweren | ein Problem melden |
| die Stellenanzeige | eine Anzeige für einen Job |
| die Miete | das Geld für die Wohnung |
| der Lärm | es ist zu laut |
| kaputt / funktioniert nicht | man kann es nicht benutzen |
| Müll trennen | den Abfall sortieren |
| nachhaltig | gut für die Umwelt |
| die Umwelt schützen | die Natur schonen |
| zuverlässig | man kann sich auf die Person verlassen |
| flexibel | die Zeit kann sich ändern |
| pünktlich | zur richtigen Zeit |
| teamfähig | kann gut mit anderen arbeiten |
| die Ausbildung | berufliches Lernen |
| das Praktikum | zur Probe in einer Firma arbeiten |
| der Kundendienst | Hilfe für Kunden |
| sich an etwas gewöhnen | es wird langsam normal |
| Nachbarschaftshilfe | Nachbarn helfen sich |
| die Werbung | eine Anzeige / Reklame |
| soziales Engagement | anderen Menschen helfen |
| gutes Benehmen | höflich sein |

You do not need every word in the text. You need the sentence that answers the question.

---

# 6. Five-minute check

1. Teil 1: five different headlines, five unused.
2. Teil 2: every answer is in the text, in order.
3. Teil 3: every match has **both** wishes. Leftover situations are **x**, not a “close” ad.
4. No empty box on the answer sheet.

# 7. Do this once tonight (about 25 minutes)

Do it closed-book. Solutions are at the bottom. Send me your letters before you look if you want them marked.

## A — Headlines

**Text 1.** Ich wollte gestern pünktlich zum Deutschkurs kommen. Der Bus kam nicht. Als ich ankam, war die Tür schon zu.

**Text 2.** Die Waschmaschine im Keller ist seit Montag kaputt. Die Hausverwaltung sagt, ein Techniker kommt erst nächste Woche. Bis dahin waschen wir bei der Nachbarin.

Headlines:

- **a** Der Kurs fällt wegen Krankheit aus.
- **b** Zu spät wegen des Busses.
- **c** Die Waschmaschine wird sofort repariert.
- **d** Warten auf die Reparatur im Keller.

## B — a / b / c

Seit drei Jahren lebt Amina in Berlin. Am Anfang fand sie die Mülltrennung schwer. Inzwischen macht sie sie jeden Tag. Schlafmittel nimmt sie nur als letzten Ausweg. Sowohl ihre Nachbarin als auch sie selbst helfen einmal im Monat im Haus.

1. Amina …
   - **a** wohnt seit drei Wochen in Berlin.
   - **b** wohnt schon drei Jahre in Berlin.
   - **c** ist vor drei Jahren aus Berlin weggezogen.
2. Schlafmittel …
   - **a** nimmt sie jeden Abend.
   - **b** sind für sie der normale erste Schritt.
   - **c** nimmt sie nur, wenn nichts anderes hilft.
3. Im Haus helfen …
   - **a** nur Amina.
   - **b** nur die Nachbarin.
   - **c** Amina und die Nachbarin.

## C — Ads (one may be x)

1. **Ayla** will abends Deutsch lernen, aber nicht am Wochenende. Mehr als 200 Euro im Monat ist zu viel.
2. **Herr Vogel** ist morgen nicht zu Hause. Er sucht jemanden im Haus, der ein Paket annimmt.
3. **Sara** will am Samstag ein kaputtes Gerät reparieren lassen, statt es wegzuwerfen. Es soll nichts kosten.
4. **Tom** sucht ein Fitnessstudio mit Schwimmbad, das heute noch offen hat.

- **A** Sprachschule Aktiv: Deutsch B1, Dienstag und Donnerstag 18:00–19:30. 180 Euro im Monat.
- **B** Paketshop am Bahnhof: Pakete können Sie selbst abholen. Geöffnet bis 20 Uhr.
- **C** Repair-Café: jeden Samstag 10–14 Uhr, kostenlos. Wir reparieren mit Ihnen.
- **D** Fitness „Fit & Gesund“: Yoga und Geräte, kein Schwimmbad. Heute bis 22 Uhr.
- **E** Deutsch am Samstag, 9–15 Uhr, 250 Euro.
- **F** Nachbarhilfe, 2. OG: Ich nehme Pakete für Nachbarn an. Bitte schreiben Sie am Abend vorher.

---

## Lösungen

**A** Text 1 → **b** (the course was not cancelled). Text 2 → **d** (*erst nächste Woche* = not today).

**B** 1 **b** (*seit drei Jahren lebt* = she still lives there). 2 **c** (*nur als letzten Ausweg*). 3 **c** (*sowohl … als auch*).

**C** 1 **A** (weekday evening, 180 Euro). E fails both the day and the price. 2 **F**. B fails because he would have to go himself. 3 **C**. 4 **x**. D has no pool.
