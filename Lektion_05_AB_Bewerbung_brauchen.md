## Grammar: brauchen vs müssen

| | Structure | Meaning |
| :--- | :--- | :--- |
| **brauchen** | brauchen + (nicht/nur) + **zu** + Infinitiv | need to / don’t need to / only need to |
| **müssen** | müssen + Infinitiv (**no zu**) | must / have to / don’t have to (*nicht müssen*) |

**Examples**
- Ich **brauche** nicht früh **aufzustehen**. = I don’t need to get up early.  
- Ich **muss** nicht früh aufstehen. = I don’t have to get up early. *(similar meaning)*  
- Ich **brauche** nur die Wörter **zu** lernen. = I only need to learn the words.

## 7 Ergänzen Sie: brauchen – müssen

**a.** Ich **brauche** nur die neuen Wörter zu lernen, dann schaffe ich die Prüfung schon.  
*(I only need to learn the new words…)*

**b.** Dein Zeugnis ist doch so gut. Du **brauchst** dir wirklich keine Gedanken um einen Job zu machen.  
*(You really don’t need to worry about a job.)*

**c.** Wenn sie nur Teilzeit arbeitet, dann **muss** sie nicht den ganzen Tag am Computer sitzen.  
*(She doesn’t have to sit at the computer all day — **muss** + no zu)*

**d.** Wenn wir drei Monate verreisen wollen, dann **müssen** wir jetzt viel Geld sparen.  
*(Then we have to save a lot of money now.)*

## 9a Ein Bewerbungsschreiben — richtige Reihenfolge

| Nr. | Textteil |
| :--- | :--- |
| **1** | Bewerbung als Verkäufer von E-Bikes |
| **2** | Sehr geehrte Damen und Herren, |
| **3** | mit großem Interesse habe ich Ihre Anzeige gelesen und möchte mich um die freie Stelle als Verkäufer von E-Bikes bewerben. |
| **4** | Wie Sie aus meinen Unterlagen ersehen können, habe ich nach meinem Realschulabschluss die Ausbildung zum Zweiradmechaniker … Erfahrungen im Verkauf sammeln. |
| **5** | Es fällt mir leicht, neue Dinge zu lernen. Außerdem macht es mir Spaß, Kunden zu beraten. Deshalb wäre ich gern als Verkäufer bei Ihnen tätig. |
| **6** | Über eine Einladung zu einem persönlichen Gespräch würde ich mich freuen. |
| **7** | Mit freundlichen Grüßen, Tibor Kelemen |
| **8** | Anlagen: Lebenslauf, Zeugnisse |

### Structure of a German Bewerbung (learn this!)
1. **Betreff** (subject): Bewerbung als …  
2. **Anrede**: Sehr geehrte …  
3. **Einleitung**: Interesse + Stelle  
4. **Qualifikation**: Ausbildung, Erfahrung  
5. **Motivation**: Warum Sie?  
6. **Gesprächswunsch**  
7. **Gruß**  
8. **Anlagen**
