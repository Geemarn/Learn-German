# B1 Leseverstehen (Reading Comprehension) - Lektion 3

## Strategie für die B1-Prüfung: Synonyme erkennen!
In the B1 reading exam, the questions almost **never** use the exact same words as the text. They use synonyms (words with the same meaning). 
*   *Text says:* "jeden Tag" -> *Question says:* "täglich"
*   *Text says:* "Erlaubnis vom Arzt" -> *Question says:* "Rezept"
*   *Text says:* "nicht schlafen" -> *Question says:* "Schlafprobleme"

## Lesetext: Wege aus der Stressfalle (Blogbeitrag)

**Lies den folgenden Text. (Read the following text).**

Hallo zusammen! 
In letzter Zeit schreiben mir viele Leser, dass sie abends nicht einschlafen können. Der Grund dafür ist meistens der hohe Druck im Beruf. Viele Menschen glauben, dass sie sofort Medikamente oder Schlafmittel nehmen müssen. Aber das sollte wirklich nur der letzte Ausweg sein! Es gibt natürlich natürliche Methoden, um sich zu entspannen. 

Erstens sollte man nach 18 Uhr keinen Kaffee mehr trinken. Zweitens ist regelmäßige Bewegung sehr wichtig. Man muss nicht täglich ins Fitnessstudio gehen. Auch ein kurzer Spaziergang an der frischen Luft kann Wunder wirken. Durch die Bewegung in der Natur kann Stress sehr gut abgebaut werden. 

Erst wenn diese Tipps nicht helfen und Sie wochenlang unter Schlafmangel leiden, sollte ein Arzt besucht werden. Der Arzt kann Sie untersuchen und Ihnen, wenn nötig, etwas verschreiben. 

Bleibt gesund! 
Eure Dr. med. Julia Sommer

## Aufgaben (Richtig oder Falsch?)

Entscheide, ob die Sätze **Richtig (R)** oder **Falsch (F)** sind.

1. **Viele Menschen können nachts nicht schlafen, weil sie Stress auf der Arbeit haben.**
2. **Dr. Sommer empfiehlt, dass man bei Schlafproblemen sofort Schlaftabletten nehmen sollte.**
3. **Um Stress abzubauen, muss man jeden Tag im Fitnessstudio trainieren.**
4. **Wenn man über einen langen Zeitraum sehr schlecht schläft, muss man zum Arzt gehen.**

## Vokabelhilfe (Vocabulary Help)
*   **in letzter Zeit** - recently / lately
*   **der Druck** - pressure (Stress)
*   **der Ausweg** - way out / resort (*der letzte Ausweg* = the last resort)
*   **Wunder wirken** - to work miracles
*   **abgebaut werden** - to be reduced (Passive voice!)
*   **leiden (unter)** - to suffer (from)
*   **verschreiben** - to prescribe
